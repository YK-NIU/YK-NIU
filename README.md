## 📦 我做的工具 · What I build

**8 款 Windows 应用，全部通过微软商店分发，全部在本机处理数据。**
*8 apps, all distributed via the Microsoft Store, all processing data on your machine.*

| 工具 | 说明 | 获取 |
| --- | --- | --- |

| **科目余额分析器**<br>Trial Balance Analyzer | 几分钟内把科目余额表的方向异常和漏记扫一遍。<br>*Scan a trial balance for direction anomalies and missed entries in minutes.* | [商店](https://apps.microsoft.com/detail/9NWV1GMRM7MR) · [详情](https://littlebeaver.top/zh/trial-balance-analyzer/) |
